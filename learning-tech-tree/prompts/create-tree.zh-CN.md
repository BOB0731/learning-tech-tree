# 可直接复制给 Codex 的提示词

```text
请参考这个 GitHub 仓库：[填仓库链接]。
先读取 AGENTS.md、docs/create-with-codex.md、docs/data-format.md 和
docs/customization.md，沿用通用查看器，不要照搬计算机范例的知识内容。

我的学科或跨学科目标：[填写]
已有基础：[填写]
终点目标：[本科毕业 / 硕士研究 / 博士毕业 / 职业能力 / 其他]
实际路径与学制：[本科、硕士、博士、直博、硕博连读或自定义；可不固定年数]
兴趣方向：[填写]
语言和详细程度：[填写]
成果是否公开：[公开的通用示例 / 私人个性化版本]

请生成完整且丰富的科技树，包括适合本学科的基础、专业知识、方法、
证据产出、沟通与实践能力。每个节点给出学习范围、具体点亮任务、真正
必要的先修、推荐背景、适用边界和可核对来源。具体关系是教学设计时请说明。

每个节点都要有来路和去向：实线是必要先修，多个条件按AND；虚线是学习
发展或选用后的应用与成果汇入，不参与解锁。不能为了连通而编造关系，也
不能要求所有可选工具都成为毕业必修。整个有向图不能有环。

不要默认固定博士年限、必须单独读硕士、某个学校要求或统一论文数量。
学校正式要求需要按实际项目核对。公开版本不含真实身份、导师、私人
笔记、学号、凭证或本地文件路径。

输出 data/<新ID>.json 和 examples/<新ID>.html，沿用仓库的构建脚本。
得到授权时运行结构校验，并分别说明学术关系与视觉交互的核查范围；如果
明确要求不检查，就不要运行检查并说明限制。已有科技树修改时保留节点ID。
仅交付本地文件；未经请求不要推送或发布。
```
