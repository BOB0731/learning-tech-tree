# Contributing

Contributions can improve the viewer, subject templates, source evidence, accessibility or documentation.

For a new subject, add a JSON file following `docs/data-format.md`, use non-personal examples, distinguish real prerequisites from optional applications, and connect every node meaningfully from start to goal. Include observable outcomes and honest evidence scope. Do not copy entire copyrighted curricula or claim institutional endorsement.

Keep subject and degree choices in data. Preserve stable IDs when revising an existing tree. Rebuild generated HTML after code or dataset changes. When authorized, run `node scripts/validate.mjs`; separately state whether academic review, browser QA or other checks were performed.

Report specific incorrect edges with source and target IDs, why the relation is wrong, and a primary source or a narrower learning scope when available. Do not post private transcripts, notes, personal program details or unauthorized research data in issues.
