# Publish this package on GitHub

1. Create your intended repository, for example `learning-tech-tree`.
2. Upload the contents of this project directory. `index.html`, `README.md`, `AGENTS.md`, `LICENSE`, `package.json` and the source/data/docs folders belong at the repository root, not inside an extra outer folder.
3. Do not upload progress backups, private notes or unrelated folders from your computer.
4. Commit the uploaded files.
5. For an online viewer, open **Settings → Pages**, choose **Deploy from a branch**, the intended branch, and **/ (root)**; save.
6. Wait for GitHub to report the actual Pages URL. Use that literal URL rather than guessing a successful deployment.

The included pages are standalone static HTML, so no package installation or build workflow is required to view the bundled version. Source changes should be rebuilt locally before uploading updated generated HTML.

[Official GitHub Pages setup](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

The ready-to-paste repository description is:

```text
Turn any learning journey into an interactive tech tree. Map prerequisites, explore connections, and track progress across any subject, skill, or educational path.
```

After publication, replace `<REPOSITORY_URL>` in shared prompts with your actual repository URL. You do not need to hard-code an account name into this project's source or examples.

The package includes an MIT license for the independently authored project. Review the intended license and public contents as the repository owner before choosing to publish. No repository, permission change, push or deployment has been performed by this package.
