# Learning Tech Tree · 通用学习科技树

把任何学科、技能或本硕博学习路径变成可缩放、可追溯、有始有终的科技树。

## 直接使用

下载仓库后双击根目录的 [index.html](../index.html)。不需要安装依赖、启动服务、登录账号或提供模型密钥。

- [计算机科学博士示例](../examples/computer-science-phd.html)：独立编写的多方向能力地图。
- [最小自定义模板](../examples/minimal-template.html)：可交给 Codex 扩展为任意学科。
- [可复制的中文提示词](../prompts/create-tree.zh-CN.md)。

此版本界面和示例内容为中文，文档提供中英文。知识点、阶段和来源可用其他语言编写；`language`只是内容语言提示，不会自动翻译界面。

## 通用在哪里

学科、阶段名称、阶段数量、起点和终点全部由 JSON 定义。可以只做本科、硕士、博士，也可以组织本硕博、直博、硕博连读、在职学习和自学目标。没有固定年限，也不要求所有人经历同一种学位顺序。

阶段可以按年、学期、能力或研究里程碑命名。模板见 [degree-paths.json](../templates/degree-paths.json)。正式课程、资格、开题、毕业和学位条件仍以本人适用制度为准。

## 让 Codex 帮你生成

把仓库链接与自己的学科、基础、目标、实际路径发给 Codex，并要求它先读取 `AGENTS.md` 和生成说明。完整提示词在 [prompts/create-tree.zh-CN.md](../prompts/create-tree.zh-CN.md)。

Codex 需要能读取或克隆仓库。这个项目提供格式、程序和生成规则，本身没有模型接口或在线自动生成服务。

Codex 生成 JSON 后，在页面点击“打开科技树”即可加载。也可以用脚本生成独立 HTML。

## 关系与进度

- 实线：真正必要的先修，多个条件按 AND 理解。
- 虚线：学习发展、可选应用或成果汇入，不参与锁定。
- 推荐背景：详情中的辅助链接，不作为图布局边。
- 每个节点都应从起点可达，并能通过合理应用走向终点。
- 每个节点有范围、点亮任务、边界与来源，不能只堆课程名称。

点击节点查看档案；“前置路径”显示必要基础；“起点→本节点→终点”显示经过当前能力的一条代表路线。左侧搜索、分支过滤，上方定位阶段；空白处拖动，滚轮或按钮缩放。

进度与笔记按每棵树的稳定 ID 分开保存在当前浏览器。备份和恢复进度不等于导入和导出课程结构。换浏览器、换来源地址、清理数据或移动文件前请备份；没有自动跨设备同步。

## 编辑与生成

只有构建/校验脚本需要 Node.js 20+；没有 npm 依赖。

```sh
node scripts/validate.mjs data/my-tree.json
node scripts/build.mjs data/my-tree.json examples/my-tree.html
```

数据规范见 [data-format.md](data-format.md)，JSON Schema 位于 `schema/tree.schema.json`。结构校验能发现循环、未知引用、阶段越界与断头分支，但不能证明学术关系准确或满足毕业条件。

## 上传 GitHub

上传本仓库文件夹里面的内容，确保 `index.html` 位于仓库根目录。不要把整个压缩包当成网页上传。GitHub Pages 可选择分支与根目录发布，具体步骤见 [publish.md](publish.md)。

## 隐私与状态

公开包没有真实学习者的学科记录、身份、导师信息、私人笔记、进度或本地路径。只包含独立编写的公共示例。应用没有上传笔记的后端；公开托管与来源网站仍有各自的日志政策。

遵照本次交付要求，未运行自动校验、测试或浏览器检查。构建时使用了跳过校验选项；没有声称这些检查已通过。后续维护者可按文档自行运行。
