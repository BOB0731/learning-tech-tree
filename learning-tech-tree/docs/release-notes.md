# Release 0.1.0

- General subject-independent and program-independent JSON format.
- Configurable stage labels/count, branches, starting point and goal.
- Independently authored computer-science doctoral example and minimal template.
- Solid prerequisites plus dashed, non-gating development/application edges.
- Start → selected capability → goal representative routes and concrete branch outputs.

## Verification status

The package and generated pages were produced without executing the automated validator, a test suite or browser QA, as requested for this delivery. Builds used `--skip-validation`. No successful validation or visual QA is claimed. Maintainers can run the documented validation commands before publishing or modifying data.

Structural validation alone is not review of academic prerequisite accuracy, a security audit, an accessibility audit or an institutional degree check.
